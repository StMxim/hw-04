# Lab 4 - JSONPlaceholder API Client

## Опис / Description

Цей проєкт реалізує клієнтську частину для роботи з публічним REST API (https://jsonplaceholder.typicode.com/users) з використанням JavaScript, DOM та пагінації.

This project implements a client-side app to work with the public REST API (https://jsonplaceholder.typicode.com/users) using JavaScript, DOM, and pagination.

## Як запустити / How to run

1. Відкрийте `index.html` у браузері.
2. Введіть кількість користувачів для завантаження (за замовчуванням 5).
3. Натисніть `FETCH USERS` для завантаження користувачів.
4. Натисніть `FETCH MORE USERS` для завантаження наступної сторінки.

Open `index.html` in your browser and follow the instructions on the page.
